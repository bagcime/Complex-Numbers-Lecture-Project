# Complex Numbers Lecture

This repository contains a lecture-style walkthrough of **complex numbers**, adapted from the UCSD tutorial on complex numbers:

> Source / reference: Complex Numbers Tutorial  
> https://sites.google.com/ucsd.edu/complex-numbers-tutorial/complex-numbers-tutorial

I recreated the material as a local HTML page so it’s easier to read, customize, and present during lectures.

---

## What’s inside

- `complex_numbers.html` (or `index.html`)  
  A standalone HTML page that explains:
  - what complex numbers are
  - the complex plane
  - algebra with complex numbers
  - polar / exponential form
  - Euler’s formula
  - basic examples

You can edit this file directly to add your own notes, screenshots, or math.
